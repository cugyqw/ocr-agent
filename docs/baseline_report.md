## 发现的问题

全部 3 处错误都属于**"知识不精确"**，而非"完全不知道"。

### 1. 诗人称号混淆（严重）

题目：请默写《静夜思》全诗，并说明作者和朝代。

模型输出：

> 李白...被后人誉为"诗仙"。他生活在盛唐时期，**享有"诗圣"之称**

**问题**：同一句话内自相矛盾。"诗圣"是杜甫，李白是"诗仙"。

### 2. 近义词错误

题目：请写出下列词语的近义词：高兴 / 立刻 / 仔细 / 美丽

模型输出：

> 4. 美丽 - **宝贵**

**问题**：应为"漂亮"。"宝贵"是"珍贵"的近义词，属于词义混淆。

### 3. 反义词错误

题目：请写出下列词语的反义词：骄傲 / 危险 / 节约 / 熟悉

模型输出：

> 3. 节约 - **消耗**
> 4. 熟悉 - **不熟悉**

**问题**：
- "消耗"搭配不当，应为"浪费"
- "不熟悉"是加否定词偷懒，标准答案应为"陌生"
- "骄傲→自卑"可接受，但小学标准答案是"谦虚"

### 4. 古诗引用偏差（轻微）

题目：「谁知盘中餐，粒粒皆辛苦」出自哪首诗？

模型答的是《悯农》**第一首**（春种一粒粟），而题面问的是**第二首**（锄禾日当午）。

作者、主旨都正确，但引用的诗句不是题面所指。

## 结论

**1.5B 通用版的中文知识储备好于预期**，古诗默写全部正确。

但存在**系统性精度问题**：知道相关概念，但区分不精确（诗仙/诗圣、宝贵/漂亮、
消耗/浪费）。这类问题**无法通过换更大模型根治**，因为它们是精度问题而非能力问题。

**RAG 知识库正好针对这类问题**：模型不需要"记住"，只需要"查对"。

## 知识库优先级（根据实测调整）

| 优先级 | 内容 | 理由 |
|---|---|---|
| **P0** | 近义词/反义词表 | 实测错误最集中 |
| **P0** | 成语词典 | 释义易不准确 |
| **P0** | 文学常识（诗人称号、朝代） | 概念易混淆 |
| P1 | 古诗词 75 首 | 模型基本会，主要用于校对 |
| P2 | 数学公式 | 实测数学题全对 |
